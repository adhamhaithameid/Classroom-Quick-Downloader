## 2024-05-23 — Teacher Landing Page and Comparison Tables
**Issues Filed:**
- Muse: create a dedicated 'For Teachers' landing page with teacher-specific use cases
- Muse: comparison pages missing feature table — visitors cannot compare at a glance

**Rationale:**
- The homepage is highly generalized. Teachers represent the core power-user base and need a dedicated narrative (grading workflows, time saved) to improve conversion and trust.
- The comparison pages currently rely entirely on paragraph text via `SeoContentPage`, which creates friction for users wanting a quick visual comparison. A feature table is a standard SaaS practice that will directly improve decision-making speed.

**Areas for Next Run:**
- The uninstall page currently provides an open text area for feedback but could benefit from structured churn-recovery questions (e.g., offering a specific help link *before* final confirmation).
- The homepage could benefit from a "What's New" section or a direct link to the changelog to show active development and build trust.
- FAQ could include specific questions about handling Google Drive virus warning delays, which were noted in previous checks but not explicitly addressed in the FAQ.
