Action Explanations

                  

                    
Dry Run Clear
Preview mode only. Oracle calculates exactly what would be deleted from non-core analytics tables and returns row counts per table, but commits nothing. Use this first before any destructive cleanup to validate scope and avoid accidental data loss.

                    
Execute Clear
Runs the same cleanup plan as Dry Run but actually deletes data. This action requires elevated verification and should be used only after reviewing Dry Run output. It does not remove core auth/config tables, but it will permanently remove matching operational data.

                    
Run SQLite Backup
Creates a point-in-time backup file under the server backup location. Use this immediately before risky operations. If cleanup or migration has unintended effects, this snapshot is your rollback anchor for the SQLite state.

                    
Step-Up Now
Starts elevated verification for the current admin session. Critical actions in this page rely on this elevated window. If buttons are rejected with permission errors, run this first and complete verification.

                    
Load Alerts
Retrieves active operational alerts such as no sync success, drift detection, backup failures, and backlog anomalies. This is the fastest health check when dashboard data looks stale or inconsistent.

                    
Verify Audit Chain
Validates append-only hash-chain integrity for admin audit records from oldest to newest. If a link is broken, response includes where validation failed. Run this after critical operations and before incident closure.

                    
Outbox Status
Shows queue health for relay pipelines: pending rows, retry counts, dead-letter presence, and relay freshness. Use this to confirm dual-DB/eventual-consistency pipelines are keeping up and not silently lagging.

                    
Load Feature Flags
Reads server-side feature flags and kill switches currently enforced by backend logic. Use this to confirm whether sensitive modules (sync, destructive endpoints, advanced admin tooling) are intentionally on or off.

                    
Dry Run Delete Older Logs
Uses the retention-days value and reports how many oracle log rows would be deleted. Safe preview mode; no records are removed.

                    
Delete Older Logs
Deletes oracle logs older than the selected retention period. Use this to keep the logs table small while preserving recent operational trace history.

                    
Delete All Oracle Logs
Irreversibly clears all oracle operation logs. Use only when resetting the environment or when log storage must be purged completely.
