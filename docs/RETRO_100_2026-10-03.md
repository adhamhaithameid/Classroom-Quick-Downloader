   client secrets appeared verbatim in session transcripts. They are in the
   session DB on disk. Rotate the npm token and Edge/API keys.
2. `continue please` was **204 of 523** real user messages — sessions stall
   often; resuming works but costs context.
3. The owner's shell prints a zoxide misconfiguration warning on nearly every
   command (init order in `~/.zshrc`) — the previous retro fixed this on the
   machine but it still reproduces in non-login agent shells.
4. `already exists` errors of all kinds are the most common string in tool
   output (91 hits) — most are store-version or duplicate-resource collisions,
   not bugs.
5. Session 05 built/published the `figma-wire`/`mcp-wire` skills from outside
   this repo — its beads/hooks noise does not belong to CQD triage.
