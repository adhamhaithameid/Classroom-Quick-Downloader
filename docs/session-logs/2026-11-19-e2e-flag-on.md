## Flag seam (documented in the spec header)

`engineBase` is module state. Nothing sets it at runtime. The only seam in a real browser is a test-only build.
`buildVariant()` stages a copy of `extension/` in tmp and edits the COPY only:

1. flag-ON copy: `let engineBase: EngineBase = 'v2'` becomes `'v3'`.
2. both copies: `NON_CHROME_TOKEN_SOURCE_WIRED = false` becomes `true`. Needed because `isApiConfigured()` (config.ts, hardened in 64b9c518) is false in Chromium for Testing (not the Google Chrome brand) while that constant is false.
3. both copies: manifest gets `oauth2.web_client_id` (stub). `identity` permission and `client_id` already ship in the manifest.
4. The background service worker gets a stubbed `chrome.storage.local cqdV2Mode: 'v3'` and a stubbed token source. The Classroom API is stubbed with a context route intercept. No real Google call.

Only the engineBase flag differs between the two copies. Repo source and `extension/.output` are untouched. If a runtime setter is added later, replace `buildVariant` with an init script.
