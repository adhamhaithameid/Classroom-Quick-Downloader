# AI Context Documentation

This folder contains documentation specifically for AI assistants working on this codebase.

## Purpose

These documents provide high-level architectural context, design decisions, and analysis that help AI understand the project before diving into code.

## Contents

- **COMPREHENSIVE_ANALYSIS.md** - Deep-dive analysis of the entire codebase including:
  - Critical issues and technical debt
  - Brilliant architectural decisions
  - Monetization strategies
  - Growth and community building plans
  - Detailed refactoring priorities

## For AI Assistants

When starting work on this project, read these documents first to understand:
1. **Architecture** - How the 3-layer system works (Extension → Cloudflare Worker → Oracle Backend)
2. **Design Decisions** - Why certain patterns were chosen (Durable Objects, batching, etc.)
3. **Known Issues** - Technical debt and areas needing improvement
4. **Project Goals** - Growth strategies and monetization plans

## For Developers

While primarily for AI context, these documents are useful for:
- Onboarding new team members
- Understanding architectural decisions
- Finding areas to contribute
- Learning about the analytics pipeline
