# CQD launch package

1. **Product angle:** One less click between you and your files. A small student-built extension removes the repetitive attachment-opening routine.
2. **Audience:** Students gathering lecture notes, worksheets and slides from Google Classroom.
3. **Core story:** Repeated individual file opening → CQD appears in the post → one Download all action → clear completion feedback → installation invitation.
4. **Key moments:** Source-native blue download controls, a visible cursor click, the green Downloaded 3 / 3 state, and the original CQD mark. The scene uses fictional class materials.
5. **Structure:** 23 seconds, landscape 1920×1080 at 30 fps. Hook 0–3s; product demonstration 3–13.1s; precise privacy language 13.1–17.5s; ONE LAST CLICK end card 17.5–23s.
6. **Messaging:** Per-post bulk downloads, fewer repeated clicks, anonymous operational metrics with no file contents in telemetry, free availability for Chrome/Firefox/Edge, independent of Google, BUILT BY ADHAM.
7. **Files:** brag.mp4; brag.jpg; brag-plan.md; composition-brief.md; share-copy.txt; share-copy-variants.md; claims-and-sources.md; asset-provenance.md; editable composition/; reproducible scripts/; validation/.
8. **Assumptions:** English, landscape, no narration. This is an illustrative demo using real control CSS and icons, not a screen recording or speed benchmark. The original instrumental soundtrack contains no sampled recordings. Success green is deepened for readable text.
9. **Excluded claims:** Fastest/best, guaranteed hours saved, user counts, testimonials, whole-course export, experimental flag accuracy, API-beta functionality, universal browser support, zero telemetry, an open-source license, and an unverified live release number.
10. **Publishing:** Upload the MP4 natively, use brag.jpg as the custom thumbnail, and include the install URL from the platform copy. Reconcile the website’s conflicting telemetry wording and release metadata before broad promotion; follow-up Beads issue Classroom-Quick-Downloader-ipxb records the evidence. No publishing was performed.

## Validation and scope

The Hyperframes check report and encoded-media measurements are in validation/. The report distinguishes nonblocking structural lint advisories from runtime, layout, motion and contrast errors. Poster frame is selected from the settled product result at 10.8 seconds and baked into frame zero. Final MP4 duration, frame count and audio are checked after that operation.

Only generated launch artifacts and Beads tracking were written in this repository. Application source was not edited by this task; the working tree already had substantial unrelated changes. Nothing was committed or pushed.
