## LinkedIn
Opening class attachments one by one is a small annoyance that gets old quickly—especially when you are gathering materials to study.

I built Classroom Quick Downloader to put the download action where it belongs: inside Google Classroom. Download an individual attachment or start downloading a post’s attachments with one click.

Under the hood: React, TypeScript and WXT, with browser download handling and local activity statistics. The project also reports anonymous operational metrics; file contents are not included in telemetry.

One lesson from building it: a small interface can hide a lot of engineering. Multi-account sessions, Drive confirmation pages, retries and clear completion states all matter when the goal is to make an everyday action feel simple.

Free for Chrome, Firefox and Edge:
https://classroom-quick-downloader.adhamhaithameid.is-a.dev/

Source and documentation:
https://github.com/adhamhaithameid/Classroom-Quick-Downloader

Classroom Quick Downloader is an independent project and is not affiliated with Google or Google Classroom.

## GitHub promotion
Classroom Quick Downloader is a React + TypeScript browser extension built with WXT. It injects individual and per-post bulk download controls into Google Classroom, coordinates browser downloads in the background, and exposes local activity stats in the popup.

The source-available repository includes the extension, marketing website, Cloudflare services, tests and architecture documentation. Operational telemetry is documented; file contents are not included in download-event payloads.
