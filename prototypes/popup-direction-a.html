Why it feels calm
  • One hero. The classroom action is the only filled element; everything else is outline-on-glass.
  • Quiet chrome. Header, labels, and footer use 11px/12px at 400–500 weight so the CTA's 15px/600 reads instantly.
  • Soft depth. Two translucent layers only (body + footer band); no nested cards in cards.
  • Motion settles. One easing curve everywhere, cubic-bezier(0.22, 1, 0.36, 1); nothing bounces.
  • History is ambient. 26px icons, one line of title, one line of meta — scannable without reading.
Direction-specific decisions
  • Engine selector is a 3-segment control with the rollback copy always visible underneath — trust copy never hides.
  • Flags are pill toggles with glowing color dots; "Both" carries a purple→cyan gradient dot (see components.html).
  • Water fill rises inside the CTA itself — the button is the progress bar. No separate banner needed for classroom runs.
  • Error rows explain the fix ("Reopen the post") instead of just naming the failure.

04 · Motion personality
Stillwater moves like it settles, not like it snaps. Durations: 200ms (hover/press), 280ms (state swaps), 360ms (water fill height). One ease: cubic-bezier(0.22, 1, 0.36, 1). Waves drift at 2.4s/3.6s counter-rotating so the crest never repeats visibly. All of it collapses under prefers-reduced-motion: reduce: waves hide, fills and counters remain (progress is information, not decoration). Full studies in effects.html.
