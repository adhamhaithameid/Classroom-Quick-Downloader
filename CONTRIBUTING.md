> Update (2026-02-15): Latest changes include CI coverage-gate hardening for extension analytics storage migration fallback, popup stats race-condition guards, structured step-up auth error handling in Oracle dashboard, and backend/worker auth-security hardening. See /CHANGELOG.md for details.

## 🚫 Code Contributions
**We do not accept Pull Requests (PRs).**
This project uses a proprietary license that does not allow derivative works or modifications. Any PRs opened will be closed without review to maintain legal compliance.

## 🐛 Bug Reports & Feedback
We strictly value your feedback! If you find a bug or have an idea:
1.  **Check existing issues** to see if it has already been reported.
2.  **Fill out our Feedback Form**: [Submit via Google Forms](https://docs.google.com/forms/d/1nB95r35O_h98odg8Y6_OrfYdjKGBqhrUCb_wFHA-RA8/edit)
3.  **Open an Issue**: You can open a GitHub Issue for discussion, but please do not submit code fixes.

## 🛡️ Security
If you discover a security vulnerability, please do **not** open a public issue. Email me directly at adhamhaithameid@gmail.com.
